# Lemo-Opuscar

**What it is.** 99 film styles for a coding agent in 15 categories, each with a short demo film made entirely in code. Install as its own Claude Code plugin (`claude plugin marketplace add lemomo-ai/lemo-opuscar`, then `claude plugin install lemo-opuscar@lemolab`); it keeps its library in `~/lemo-opuscar` and each film in the folder you start from.

**Licence.** Code MIT; the style texts (every STYLE.md) and image prompts CC BY-NC 4.0; demo films CC BY 4.0; the Clawd character is Anthropic's and not licensed. So: use the plugin itself, never copy its style texts into this skill or into anything the user sells.

**The method.** Pick a style by what the picture looks like, watch its demo, then ask the agent for a film in that style about the user's story ("a 45-second film in the watercolor style about ..."). The style file tells the agent the look, the motion and the tools. Built and tested for Claude at high effort.

**Use it for.** Route B films where a strong named look carries the story. Show its gallery in the interview.

**Make it the user's.** Use a style as a starting point and override palette and type from `Look.md`; Lemo-Opuscar supports making a style your own.

**Where it fails.** Text-heavy explainers (use Explainer Studio or the motion boards), content for sale when the style texts are CC BY-NC.
