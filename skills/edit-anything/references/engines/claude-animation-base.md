# Claude Animation Base

**What it is.** A starter kit for hand-drawn character animation in p5.js and p5.brush, by John Heibel, based on the music video "I'm Upping My P(doom)". MIT, except the Clawd character, which belongs to Anthropic and is not licensed for the user's own work.

**The method.** The model storyboards first, builds shot by shot, renders contact sheets to check its own work, and writes the MP4. Its guide's rules: handmade, alive, one piece, no text, transitions always, something happens in every scene, brush strokes, flat 2D and boiling linework, timing for the viewer, the principles of character animation. A headless renderer makes contact sheets, frame strips, stills and the MP4.

**Use it for.** Route B films with a hand-drawn character; swap Clawd for the user's own character.

**Needs.** Node, Chrome, ffmpeg. Without a GPU the watercolour fills are slow; ask the agent to avoid them.

**Where it fails.** Text-heavy content (it is built for no text), photorealism.
