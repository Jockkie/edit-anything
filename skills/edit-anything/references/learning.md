# Learning: checks.md and the feedback loop

Every video should make the next one faster and better. Two things carry over: the style system (`Look.md`) and the checks file (`checks.md`, template in `templates/checks.md`).

## checks.md

- Every correction the user makes becomes one line: **DO** or **DON'T**, in plain words, with the date. "DON'T put titles over the speaker's mouth (2026-11-17)."
- Before rendering, read `checks.md` and check the contact sheet against every line. Report the lines you checked.
- Keep it short: merge lines that say the same thing; remove a line the user overrules.

## After publishing (optional, with consent)

Ask, once, whether the user wants to read the first numbers together after 48 hours:
- **Retention at 3 seconds:** did the hook hold? Low → the first frame did not explain itself with the sound off.
- **Average view duration and the drop-off point:** where did people leave? Look at what was on screen and said there.
- **The action from the goal:** clicks, replies, sign-ups.

Write what the numbers say into `checks.md` as DO or DON'T with the number as evidence ("DO open on the result: reel 3 held 71% at 3 s against 48% for reel 2"). Numbers only from the user or the platform, never estimated.

## The second video

Start from `Look.md`, `checks.md` and the last board. Ask only what is new. The goal: the second video takes a fraction of the first.
